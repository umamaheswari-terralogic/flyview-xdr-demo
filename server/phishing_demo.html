Why this matters

Real phishing pages use this exact technique to get a file onto your system with zero interaction beyond opening a link. The file itself is often disguised — a misleading name, an icon that mimics a PDF or Word doc, or, as in this demo, an extension like .exe that makes it look like a program — to trick you into opening it afterward. In this demo the file is really a plain PNG image renamed to look like an executable — it cannot run any code — but the delivery mechanism and disguise are identical to what attackers use for genuinely malicious payloads.

What to watch for

  • A download starts immediately after opening a link, with no click required.
  • Unexpected files appearing in your Downloads folder from a page you just visited.
  • Filenames that don't match what you were expecting (e.g. "invoice.pdf.exe").
  • Urgency or pressure in the email/message that got you to click in the first place.
